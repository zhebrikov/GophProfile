# Kubernetes manifests

Источник правды для деплоя в Kubernetes — Helm chart:

**[helm/gophprofile/](../helm/gophprofile/)**

Там находятся Deployment, Service, Ingress, ConfigMap, Secret, HPA, ServiceMonitor,
NetworkPolicy, RBAC, Job миграций и опциональная локальная инфраструктура
(Postgres, MinIO, RabbitMQ).
